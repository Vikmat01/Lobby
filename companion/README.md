# Lobby Companion

Android-приложение для [Lobby](../README.md): управляй лаунчером на ПК с телефона.

- Запуск игр на ПК и установка игр Steam и Epic
- Загрузки на ПК с прогрессом
- Game Bro: уровень, челленджи, замена челленджей
- Библиотека с обложками, поиском и фильтрами, достижения Steam
- Друзья Steam: кто в сети и во что играет
- Уведомления в приложении: игра запущена, установка закончена, новый уровень

## Подключение

1. На ПК: Lobby → Настройки → Телефон → «Подключить телефон». Появится QR-код.
2. На телефоне: Lobby Companion → «Подключить» и навести камеру на код. Можно и обычной камерой телефона.
3. Телефон и ПК должны быть в одной сети Wi-Fi. Если Windows спросит про брандмауэр, разреши Lobby доступ в частных сетях.

Lobby на ПК слушает порт 47820 только когда включён «Доступ с телефона». Каждый запрос с телефона подписан токеном, который выдаётся при подключении по одноразовому коду. Отключить телефон можно и в настройках Lobby, и в самом приложении.

## Сборка

Нужны JDK 17+, Android SDK (platform 35) и Gradle 8.11+.

```bash
cd companion
gradle assembleRelease          # app/build/outputs/apk/release/app-release.apk
gradle recordPaparazziDebug     # скриншоты экранов в app/src/test/snapshots
```

Ключ подписи в репозиторий не входит. Для подписанной сборки создай рядом `keystore.properties`:

```
storeFile=путь/к/lobby-companion.jks
storePassword=...
keyAlias=lobby
keyPassword=...
```

Без него `assembleRelease` соберёт неподписанный APK. Обновления ставятся поверх только при подписи тем же ключом.
